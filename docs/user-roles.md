# User Roles & Capabilities

## 1. DONOR
**Who:** Restaurants, caterers, wedding/event organizers.
**Capabilities:**
* Register and manage profile (location, contact info).
* Configure default food information (typical food, prep time, storage, pickup preference).
* Create, edit, and cancel donations.
* View donation history, claims, and pickup status.
* View personal Impact Score and Tier.

## 2. NGO
**Who:** Verified NGOs, shelters, food banks, community organizations.
**Capabilities:**
* Register and provide organization details.
* Specify food requirements (types, typical quantity, operating hours).
* Define maximum pickup radius.
* Browse nearby donations and view algorithmically recommended matches.
* Claim donations.
* Manage pickups and mark food as received.
* View history and Impact Score.

## 3. VOLUNTEER (Post-MVP)
**Who:** Individuals offering to transport food from Donors to NGOs.
**Capabilities (Future):**
* Register, provide location, and vehicle info.
* Set availability windows.
* View and accept pickup requests.
* Collect and deliver food to complete the lifecycle.
* Earn Impact Points for reliability and on-time performance.

## 4. ADMIN
**Who:** Platform operators.
**Capabilities:**
* View user metrics (Total users, Active donors, Verified NGOs).
* Approve/Reject NGO and Donor accounts.
* Suspend suspicious accounts.
* Monitor donation lifecycle (Available, Completed, Expired, Failed).
* Handle user reports and cancel suspicious donations.
* View detailed audit logs for all administrative actions.
